# Growbe · Recursos del showroom

Modelos optimizados, miniaturas y visor para [Growbe en Tiendanube](https://growbe.mitiendanube.com/).

Este repositorio aloja recursos estáticos. La experiencia se monta dentro de Tiendanube mediante Google Tag Manager.

- Modelos GLB: Meshopt + texturas WebP de hasta 1024 px.
- Visor Three.js r180; carga al abrir una experiencia.
- Sin claves, datos de clientes, OAuth ni backend.
- Licencias y atribuciones por recurso: [v3/CREDITOS.html](v3/CREDITOS.html).
- Las escenas, precios y medidas son de demostración.
